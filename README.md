# 木魚 · 功德

一个零依赖、单文件的电子木鱼页面。黑色禅意背景，纯白木槌逆时针挥落敲击木鱼，
带下压平移的拟真敲击动作、多层光效粒子反馈，以及 Web Audio 实时合成的清脆木鱼声。

## 使用

```text
muyu.html   页面本体（单文件，无外部 JS/CSS 依赖）
my.png      木鱼素材（黑底白鱼，页面通过 SVG 滤镜实时抠除黑底）
```

两个文件放在**同一目录**，双击 `muyu.html` 用浏览器打开即可（Chrome / Edge / Firefox / Safari 均可，
无需服务器）。

## 玩法

| 操作 | 效果 |
|------|------|
| 点击页面任意位置 | 敲一下 |
| 按空格 / 回车 | 敲一下（支持长按防重复） |
| 狂点连击 | 每次点击独立结算，支持手速连敲 |
| 「自动诵经」按钮 | 以 1.15–1.8s 随机拟人间隔自动敲击 |

功德计数通过 `localStorage` 持久化，关闭页面不丢；
换浏览器或清除站点数据后从 0 重新积攒。

## 效果细节

- **敲击动作**：木槌（短柄 + 圆头，SVG 绘制）从左上方逆时针挥落，触底前叠加整体下压平移，
  反弹回摆后缓缓举回，全程约 0.5s
- **受击反馈**：木鱼 squash 压扁回弹、接触点白色闪光、涟漪扩散、火花扇形飞散、
  「功德 +1」飘字、舞台微震
- **光效层次**：木鱼背后佛光（缓慢呼吸、敲击时爆亮）+ 脚下光斑 + 接触闪光三层联动
- **氛围**：上浮微尘、衬线排版、朱砂印章「靜」
- **首次敲击后**，底部操作提示自动淡出

## 声音实现（无音频文件）

木鱼声由 Web Audio API 物理建模实时合成：

1. **非谐波共振模态簇**：955 / 1530 / 2430 / 3760 Hz 四个正弦振荡器独立指数衰减，
   构成木质空腔的「笃」声主体
2. **敲击瞬态**：3.4kHz 带通白噪声 26ms，模拟锤头触木的「嗒」
3. **腔体共鸣**：205→140Hz 低频正弦 60ms，提供身体感
4. **去机械感**：每次敲击随机 ±2.5% 失谐 + 力度随机，总线压缩器防破音

首次交互时自动创建并解锁 `AudioContext`（浏览器自动播放策略要求）。

## 自定义调节

打开 `muyu.html` 直接改以下位置（均有注释）：

| 想调什么 | 位置 |
|----------|------|
| 音色（更沉/更脆） | JS 中 `knockSound()` 的 `modes` 频率与衰减数组 |
| 音量 | `master.gain.value = .85` |
| 敲击节奏（自动模式） | `autoLoop()` 中 `1150 + Math.random() * 650` |
| 木槌举角 | CSS `@keyframes malletSwing` 与 `.mallet` 的 `rotate(28deg)` |
| 敲击力度感 | keyframes 中的 `translateY(77px)` 下压量 |
| 敲击点位置 | JS 中 `HIT_X / HIT_Y`（设计坐标） |

## 布局说明

页面采用 640×830 固定设计坐标系，所有元素像素级定位，
JS 根据窗口尺寸对整个舞台 `transform: scale()` 等比缩放，桌面与手机自动适配。

木鱼素材黑底由 `feColorMatrix` 滤镜按亮度映射为 alpha 透明度，
不依赖背景色混合，任何动画状态下都不会出现背景接缝。
